Using them

Execute any file as-is and you get the demo above. Each one ends with a marked DEMO BUILD block — delete it and you have a bare library, then build your own menu with Window:AddTab and AddToggle / AddSlider / AddDropdown / AddKeybind / AddColorpicker and the rest. Every element takes a Callback, which is where your own functions attach.

Colours live in a registry rather than being baked into each instance, so the colourpickers on the Theme tab retint the entire interface while it is running.
